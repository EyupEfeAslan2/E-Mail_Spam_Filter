Spam Hassasiyeti (Sensitivity)

Derin öğrenme modelinin (DistilBERT) bir e-postayı spam olarak sınıflandırması için gereken eşik değerini belirler. Düşük değerler daha agresif spam filtresi sağlar, yüksek değerler ise sadece çok emin olunan durumlarda spam der.

Sistem Mimarisi

1. Bloom Filter (Hızlı Katman)

Bit array ve hash fonksiyonlarıyla çalışan veri yapısı. Daha önce spam olarak işaretlenmiş metinleri düşük bellek kullanımıyla anında yakalar.

Kullanılan Veri Yapıları: Bloom Filter (Byte Array), Kriptografik Hash (SHA-256)
Dosya Konumu: core/bloom_filter.py

2. DistilBERT (Derin Katman)

Derin öğrenme modeli. Metnin anlamsal bütünlüğünü analiz ederek karmaşık spam örüntülerini tespit eder.

Dosya Konumu: core/model.py, core/train.py

3. Sayfa Geçişleri (Stack)

Bu arayüzdeki sayfa geçişleri, tarayıcı geçmişini simüle eden özel bir Stack (Yığın) veri yapısıyla yönetilmektedir.

Kullanılan Veri Yapısı: Stack (LIFO)
Dosya Konumu: ui/app.js (Satır 5-31)

Kod Düzeyinde Veri Yapıları

Hash Fonksiyonu (Kriptografik Özetleme)

Bloom Filter'a gelen metinleri indekslere dönüştürmek için SHA-256 kullanılır. Modüler aritmetik ile (% size) dizinin boyutuna sığdırılır.

def _hash_item(self, item: str, i: int) -> int:
    # Metni ve döngü numarasını birleştirip SHA-256'dan geçir
    hash_object = hashlib.sha256(f"{i}:{item}".encode('utf-8'))
    
    # 16'lık tabandaki özeti tam sayıya çevir ve dizi boyutuna mod al
    return int(hash_object.hexdigest(), 16) % self.size

Stack (Yığın) LIFO

Sayfalar arası gezinirken, bir önceki sayfayı hatırlamak için (Tarayıcı geçmişi gibi) JavaScript üzerinde özel bir Stack (LIFO - Son Giren İlk Çıkar) mimarisi yazılmıştır.

class NavigationStack {
    constructor() { this.items = []; }

    push(pageId) { this.items.push(pageId); } // Yeni sayfaya girince
    
    pop() { 
        if (this.isEmpty()) return null;
        return this.items.pop(); // "Geri Dön" butonuna basınca
    }
}

Bloom Filter (Bit Array)

Bir e-postanın veri tabanında olup olmadığını çok hızlı kontrol eden O(k) karmaşıklıklı veri yapısı. Klasik bir Array'den çok daha az bellek tüketir (Byte dizisi). 

def add(self, item: str) -> None:
    # O(k) zaman karmaşıklığı: K adet hash fonksiyonu çalıştırılır
    for i in range(self.hash_count):
        index = self._hash_item(item, i)
        self._set_bit(index) # O indeksteki biti 1 (True) yap
